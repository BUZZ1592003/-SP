# Sohan Chandra Pani — Developer Portfolio

A modern, interactive developer portfolio built to showcase my work, technical skills, experience, and journey as a web developer.

The portfolio combines bold typography, interactive interfaces, 3D elements, technical visual systems, and responsive layouts to create an experience that feels more like a digital system than a traditional portfolio.

## About the Project

This portfolio was designed and developed from the ground up as a personal space to showcase what I build and what I'm currently learning.

Instead of using a traditional card-based portfolio layout, the website explores a more technical and experimental visual direction with:

- Interactive 3D elements
- Animated SVG systems
- Technical grid layouts
- Responsive project showcases
- Interactive service previews
- Development workflow visualizations
- Signal/radar-inspired contact interface
- Scroll-based animations
- Mobile-specific layouts

## Running Locally

Clone the repository:

```bash
git clone https://github.com/BUZZ1592003/-SP.git
```

Move into the project:

```bash
cd -- -SP
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

---

## Production Build

Create an optimized production build:

```bash
npm run build
```

Run the production server locally:

```bash
npm start
```

---

## Deployment

The portfolio is deployed using **Vercel** and connected to this GitHub repository.

Updates pushed to the production branch are automatically built and deployed through Vercel.

```text
Local Development
       ↓
     Git
       ↓
    GitHub
       ↓
    Vercel
       ↓
buzzlightyear.tech
```
